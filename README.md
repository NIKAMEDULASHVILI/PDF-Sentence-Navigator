# PDF Sentence Navigator

## აღწერა
PDF Sentence Navigator არის Google Chrome Extension (Manifest V3), რომელიც მომხმარებელს საშუალებას აძლევს გახსნას ლოკალური PDF დოკუმენტები ბრაუზერში და გადაადგილდეს ტექსტურ წინადადებებს შორის კლავიატურის გამოყენებით.

გაფართოება მუშაობს სრულად ლოკალურად. PDF ფაილები არ იტვირთება ინტერნეტში და არ იგზავნება გარე სერვერებზე.

## ფუნქციები
- ლოკალური PDF ფაილების არჩევა
- PDF დოკუმენტის გახსნა სპეციალურ Viewer-ში
- PDF ტექსტის ანალიზი
- წინადადებების ავტომატური დაყოფა
- შემდეგ წინადადებაზე გადასვლა:
  - `Tab`
- წინა წინადადებაზე დაბრუნება:
  - `Shift + Tab`
- მიმდინარე წინადადების ვიზუალური მონიშვნა
- მუშაობა ოფლაინ რეჟიმში

## მუშაობის პრინციპი

1. მომხმარებელი ირჩევს PDF ფაილს.
2. PDF იტვირთება PDF.js-ის საშუალებით.
3. დოკუმენტიდან ხდება ტექსტის ამოღება.
4. ტექსტი იყოფა წინადადებებად.
5. მომხმარებელი გადაადგილდება წინადადებებს შორის კლავიატურის გამოყენებით.

## უსაფრთხოება
