# PDF Sentence Navigator

## აღწერა
PDF Sentence Navigator არის Google Chrome-ის გაფართოება (Extension), რომელიც მომხმარებელს საშუალებას აძლევს გახსნას ლოკალური PDF ფაილები და გადაადგილდეს წინადადებებს შორის კლავიატურის ღილაკების გამოყენებით.

## ფუნქციები
- ლოკალური PDF ფაილების გახსნა
- PDF დოკუმენტის ბრაუზერში ჩვენება
- შემდეგ წინადადებაზე გადასვლა **Tab** ღილაკით
- წინა წინადადებაზე დაბრუნება **Shift + Tab** ღილაკით
- მუშაობს სრულად ლოკალურად, ფაილები არ იგზავნება გარე სერვერზე

## ინსტალაცია
1. გახსენით Google Chrome.
2. გადადით მისამართზე `chrome://extensions/`.
3. ჩართეთ **Developer mode**.
4. დააჭირეთ **Load unpacked**.
5. აირჩიეთ `PDFExtension` პროექტის საქაღალდე.

## გამოყენება
1. დააჭირეთ გაფართოების (Extension) აიქონს.
2. აირჩიეთ ლოკალური PDF ფაილი.
3. PDF გაიხსნება Viewer-ში.
4. შემდეგ წინადადებაზე გადასასვლელად დააჭირეთ **Tab**.
5. წინა წინადადებაზე დასაბრუნებლად დააჭირეთ **Shift + Tab**.
